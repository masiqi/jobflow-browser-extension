# Immersive Translate UI reference

- Researched: 2026-09-10
- Purpose: interaction hierarchy only, not visual copying

## Public observations

Immersive Translate documentation describes a floating window icon on the right side of a web page and an extension panel for quick actions. Its usage documentation routes deeper configuration to a plugin settings page. The 1.30.3 changelog says the floating-ball sidebar entry is no longer shown by default and can be enabled in settings.

Sources:

- [Immersive Translate introduction](https://immersivetranslate.com/docs/)
- [Immersive Translate usage](https://immersivetranslate.com/docs/usage/)
- [Immersive Translate FAQ](https://immersivetranslate.com/docs/faq/)
- [Immersive Translate changelog](https://immersivetranslate.com/docs/CHANGELOG/)

## Applicable lesson

- Keep the in-page entry small and optional.
- Put page-context actions near the page.
- Put dense and infrequent configuration in a larger extension-owned surface.
- Do not copy the reference product's branding, icons, visual layout, or translation-specific interaction.
